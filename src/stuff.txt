

#include <Arduino.h>

#define SLAVE_ADDR 0x08

void i2cInit() {
  // Set prescaler to 1
  TWSR = 0x00;

  // Set SCL frequency to ~100kHz
  TWBR = 72;

  // Enable TWI
  TWCR = (1 << TWEN);
}

void i2cStart() {
  TWCR = (1 << TWINT) | (1 << TWSTA) | (1 << TWEN);

  while (!(TWCR & (1 << TWINT)));
}

void i2cStop() {
  TWCR = (1 << TWINT) | (1 << TWSTO) | (1 << TWEN);
}

void i2cWrite(uint8_t data) {
  TWDR = data;

  TWCR = (1 << TWINT) | (1 << TWEN);

  while (!(TWCR & (1 << TWINT)));
}

void setup() {
  Serial.begin(9600);

  i2cInit();
}

void loop() {

  i2cStart();

  // Send slave address + write bit
  i2cWrite((SLAVE_ADDR << 1) | 0);

  // Send data
  i2cWrite(69);

  i2cStop();

  Serial.println("Sent 69");

  delay(1000);
}

# 1. Understanding Registers

This is the REAL foundation.

When you do:

```cpp id="ab2r61"
TWCR = (1 << TWEN);
```

you are literally writing bits into hardware memory.

A register is basically:

* a tiny hardware control panel
* usually 8 bits

Example:

```text id="7p9brj"
00000100
```

Each bit controls something.

---

# Example

```cpp id="4lgqgr"
(1 << TWEN)
```

If:

```cpp id="0c2k3x"
TWEN = 2
```

then:

```text id="6xbkq7"
1 << 2
=
00000100
```

Meaning:

> “turn ON bit 2”

That enables the I2C peripheral.

Tiny electricity goblin switches.

## how would reading work?

Hint:

* MCU stores received byte in:

```cpp id="f6vr1q"
TWDR
```

Think through the sequence before asking me for code.
That’s how firmware knowledge actually sticks instead of becoming copy-paste soup.


Start   
        |A6|A5|A4|A3|A2|A1|A0|R/W|      - Device Address
Ack
        |B7|B6|B5|B4|B3|B2|B1|B0|       - Internal Register Address
Ack
        |D7|D6|D5|D4|D3|D2|D1|D0|       - Data
Stop

To Start: SDA Goes LOW, While SCL is HIGH
ACK : SDA goes LOW
NACK: SDA remains HIGH 
To Stop: SDA Goes HIGH, While SCL is HIGH

To send each bit:
    SCL LOW
    Write the bit to SDA, 
    SCL HIGH
    rinse and repeat

After 8 bits:
    Release SDA (pinMode(SDA, INPUT))
    SCL HIGH
    Read SDA
    SCL LOW
